System settings and data readiness
Admin access uses the configured email and LOGICADE_ADMIN_KEY password to obtain a signed admin session. This is one configured administrator account, not a role-management system. The Supabase service-role key remains server-only.
Research data gaps
  • Online hints and first-clear rewards use the server ledger; offline wallet values remain provisional until synchronization.
  • Browser outbox counts and last successful upload are reported after an authenticated sync status update.
  • Explicit exits and restarts are recorded as abandoned or restarted attempts; browser crashes and individual question retries can still leave incomplete telemetry.
  • Pretest/posttest and survey tables require approved instrument data entry before analysis is possible.
