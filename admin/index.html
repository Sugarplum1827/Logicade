System settings and data readiness
Admin access uses the server-side LOGICADE_ADMIN_KEY. The current app has a shared admin key, not per-admin accounts or role permissions. Do not expose the Supabase service-role key in the browser.
Research data gaps
  • Coins are currently held in client storage; a database ledger schema and sync allowlist are being added, but app-side transaction writing still needs to be connected.
  • Device outbox counts are local and are not currently reported to this admin dashboard.
  • Incomplete sessions, exit actions, restarts, and question retries are not consistently emitted as durable records.
  • Pretest/posttest and survey tables require approved instrument data entry before analysis is possible.

    
Admin refreshes only when requested or when switching to a live data section. Data reflects records that reached the server.
